# LearnLoop 프로젝트 기획서

## 1. 프로젝트 이름

LearnLoop — AI Personal Study Coach

## 2. 문제 정의

대학생과 자격증 수험생은 강의자료, PDF, 전공 교재 등을 활용해 공부하지만, 학습 과정에서 다음과 같은 어려움을 겪는다.

첫째, 강의자료의 양이 많아 핵심 내용을 빠르게 파악하기 어렵다.

둘째, 이해되지 않는 내용을 확인하기 위해 인터넷 검색이나 생성형 AI를 사용하더라도 답변이 실제 강의자료의 내용과 일치하는지 확인하기 어렵다.

셋째, 학습한 내용을 스스로 점검하기 위한 문제를 직접 만드는 데 시간이 많이 들고, 기존 문제만 반복해서 풀 경우 개인의 취약 영역을 집중적으로 학습하기 어렵다.

넷째, 기존의 일반적인 AI 챗봇은 이전 문제 풀이 기록, 오답 유형, 취약 단원과 같은 개인의 장기적인 학습 상태를 지속적으로 관리하지 못하는 경우가 많다.

따라서 학습자료를 기반으로 정확한 정보를 제공하고, 문제 풀이 결과와 학습 기록을 축적하여 개인별 취약 영역을 분석한 뒤 이후 학습과 복습에 반영할 수 있는 통합형 AI 학습 지원 서비스가 필요하다.

## 3. 타겟 사용자

LearnLoop의 핵심 타겟 사용자는 PDF 강의자료나 학습자료를 기반으로 공부하는 대학생 및 시험 준비생이다.

주요 사용자는 다음과 같은 특징을 가진다.

- 수업에서 제공된 PDF, 강의 슬라이드, 요약 자료 등을 이용해 공부한다.
- 시험 전에 많은 양의 자료에서 핵심 내용을 빠르게 정리하고 싶어 한다.
- 학습한 내용을 실제로 이해했는지 문제를 통해 확인하고 싶어 한다.
- 오답을 기록하고 반복해서 복습하는 과정이 번거롭다고 느낀다.
- 자신이 어떤 단원이나 개념에 약한지 객관적으로 파악하기 어렵다.
- 일반적인 AI 챗봇이 아닌, 자신의 학습자료와 학습 기록을 기반으로 개인화된 도움을 받고 싶어 한다.

### 핵심 사용자 예시

대학 전공 수업을 듣는 학생이 시험을 준비하면서 교수자가 제공한 PDF 강의자료를 LearnLoop에 업로드한다.

사용자는 AI에게 강의자료 내용을 질문하거나 핵심 내용을 요약받을 수 있으며, 해당 자료를 기반으로 생성된 예상 문제를 풀 수 있다.

LearnLoop는 문제 풀이 결과와 오답 기록을 저장하고 취약한 개념을 분석하여 이후 학습 시 해당 영역을 중심으로 추가 문제와 복습 내용을 제공한다.

### 보조 타겟 사용자

- 자격증 시험 준비생
- 온라인 강의 수강생
- 취업 필기시험 준비생
- 개인적으로 PDF 교재나 문서를 활용해 공부하는 학습자

초기 MVP에서는 모든 학습자를 대상으로 하기보다, **PDF 기반으로 시험 공부를 하는 대학생**을 가장 우선적인 사용자로 설정한다.

## 4. 해결 방법

LearnLoop는 사용자가 업로드한 PDF 학습자료를 AI가 분석하고, 해당 자료를 기반으로 학습을 진행할 수 있도록 지원한다.

사용자는 학습자료에서 궁금한 내용을 질문하거나 핵심 내용을 요약받을 수 있으며, AI는 업로드된 자료를 검색하여 근거가 있는 답변을 제공한다.

또한 학습자료의 내용을 기반으로 예상 문제를 자동 생성하고, 사용자가 문제를 풀면 정답과 오답 결과를 저장한다.

저장된 문제 풀이 기록을 바탕으로 사용자가 자주 틀리는 개념이나 취약한 영역을 분석하고, 이후 학습에서는 해당 취약 영역을 중심으로 새로운 문제와 복습 내용을 제공한다.

이를 통해 LearnLoop는 다음과 같은 반복 학습 구조를 제공한다.

1. 학습자료 업로드
2. AI 기반 자료 분석
3. 질문 및 핵심 내용 학습
4. 예상 문제 생성
5. 문제 풀이
6. 정답 및 오답 기록
7. 취약 영역 분석
8. 맞춤형 복습 문제 생성
9. 이후 학습에 이전 기록 반영

즉, LearnLoop는 단순히 질문에 답변하는 AI가 아니라 사용자의 학습 상태를 지속적으로 기록하고, 그 기록을 다음 학습 과정에 활용하는 개인화 AI 학습 코치 역할을 한다.

## 5. 핵심 기능

LearnLoop의 핵심 기능은 사용자가 업로드한 학습자료를 기반으로 학습을 진행하고, 학습 결과를 기록하여 개인화된 복습을 제공하는 데 초점을 둔다.

### 1. 학습자료 PDF 업로드

사용자는 공부할 PDF 강의자료를 업로드할 수 있다.

업로드된 PDF의 텍스트를 추출하고, 문서를 작은 단위로 분할하여 이후 AI 검색과 질문 답변에 활용할 수 있도록 저장한다.

### 2. 강의자료 기반 질문 답변

사용자가 업로드한 자료에 대해 질문하면 AI가 관련 내용을 검색하고, 해당 자료를 근거로 답변한다.

가능하면 답변과 함께 참고한 페이지 또는 문서 구간을 표시하여 답변의 근거를 확인할 수 있도록 한다.

### 3. 핵심 내용 요약

AI가 업로드된 강의자료를 분석하여 중요한 개념과 핵심 내용을 요약한다.

사용자는 긴 강의자료를 처음부터 모두 읽기 전에 주요 내용을 빠르게 확인할 수 있다.

### 4. 예상 문제 자동 생성

AI가 학습자료를 기반으로 예상 문제를 자동 생성한다.

초기 MVP에서는 객관식 문제를 중심으로 구현하고, 각 문제에는 다음 정보를 포함한다.

- 문제
- 선택지
- 정답
- 해설
- 관련 학습 주제

### 5. 문제 풀이 및 채점

사용자는 AI가 생성한 문제를 직접 풀 수 있다.

답안을 제출하면 정답 여부와 해설을 확인할 수 있으며, 풀이 결과는 사용자 학습 기록에 저장된다.

### 6. 오답 및 학습 기록 저장

사용자가 어떤 문제를 풀었는지, 어떤 문제를 맞히거나 틀렸는지 기록한다.

주요 저장 항목은 다음과 같다.

- 문제
- 선택한 답
- 정답
- 정답 여부
- 관련 주제
- 풀이 날짜

이 기록은 이후 개인화 학습에 활용한다.

### 7. 취약 영역 분석

저장된 문제 풀이 결과를 분석하여 사용자가 자주 틀리는 주제나 개념을 파악한다.

예를 들어 특정 단원의 문제 정답률이 낮다면 해당 단원을 취약 영역으로 표시할 수 있다.

### 8. 맞춤형 복습 문제 생성

AI는 사용자의 취약 영역을 참고하여 해당 영역을 중심으로 새로운 복습 문제를 생성한다.

이를 통해 모든 내용을 동일하게 반복하는 것이 아니라, 사용자가 부족한 부분을 집중적으로 다시 학습할 수 있도록 한다.

### 핵심 학습 흐름

PDF 업로드  
→ 자료 기반 질문 및 요약  
→ 예상 문제 생성  
→ 문제 풀이  
→ 정답·오답 기록  
→ 취약 영역 분석  
→ 맞춤형 복습 문제 생성

## 6. AI 활용 방식

LearnLoop는 생성형 AI를 중심으로 RAG와 Long-term Memory를 결합하여 개인화된 학습 경험을 제공한다.

### 1. RAG 기반 강의자료 질문 답변

사용자가 PDF 강의자료를 업로드하면 문서의 텍스트를 추출하고 일정한 크기로 분할한다.

분할된 텍스트는 임베딩 모델을 통해 벡터 형태로 변환한 뒤 벡터 데이터베이스에 저장한다.

사용자가 질문하면 질문과 관련성이 높은 문서 조각을 검색하고, 검색된 내용을 생성형 AI에게 함께 전달하여 답변을 생성한다.

이를 통해 일반적인 지식만을 기반으로 답변하는 것이 아니라 사용자가 직접 업로드한 강의자료를 근거로 답변할 수 있도록 한다.

처리 흐름은 다음과 같다.

PDF 업로드  
→ 텍스트 추출  
→ 문서 분할  
→ 임베딩 생성  
→ 벡터 DB 저장  
→ 사용자 질문  
→ 관련 문서 검색  
→ 검색 결과 + 질문을 LLM에 전달  
→ 자료 기반 답변 생성

### 2. AI 기반 핵심 내용 요약

업로드된 학습자료의 주요 내용을 생성형 AI가 요약한다.

문서 전체를 한 번에 처리하기보다 필요한 경우 여러 구간으로 나눈 뒤 각 구간의 핵심 내용을 추출하고, 이를 다시 종합하여 전체 요약을 생성한다.

요약 결과에는 주요 개념, 핵심 키워드, 중요 내용 등을 포함할 수 있다.

### 3. AI 기반 예상 문제 생성

생성형 AI는 강의자료의 내용을 기반으로 객관식 예상 문제를 생성한다.

각 문제에는 다음과 같은 구조화된 정보를 생성하도록 한다.

- 문제 내용
- 선택지
- 정답
- 해설
- 관련 학습 주제

AI의 응답을 JSON 형식으로 제한하여 백엔드에서 안정적으로 처리할 수 있도록 한다.

### 4. Long-term Memory 기반 학습 기록 관리

LearnLoop는 사용자의 학습 결과를 장기간 저장하고 이후 학습에 활용한다.

저장되는 주요 학습 정보는 다음과 같다.

- 풀이한 문제
- 사용자가 선택한 답
- 정답 여부
- 문제와 관련된 학습 주제
- 주제별 정답률
- 자주 틀리는 개념
- 최근 학습 날짜

이 정보는 데이터베이스에 사용자별로 저장한다.

단순히 이전 대화를 그대로 저장하는 방식이 아니라, 학습에 필요한 정보를 구조화하여 관리하는 방식으로 Long-term Memory를 구현한다.

### 5. 취약 영역 분석

사용자의 문제 풀이 기록을 기반으로 주제별 성취도를 계산한다.

예를 들어 특정 주제에서 오답 비율이 높거나 반복적으로 틀리는 경우 해당 주제를 취약 영역으로 판단한다.

초기 버전에서는 복잡한 머신러닝 모델을 사용하기보다 정답률과 오답 횟수 등을 기준으로 취약 영역을 판단한다.

### 6. 개인화 복습 문제 생성

취약 영역으로 판단된 학습 주제와 이전 오답 기록을 생성형 AI에게 전달한다.

AI는 해당 정보를 참고하여 기존 문제를 그대로 반복하지 않고 비슷한 개념을 다른 방식으로 묻는 새로운 복습 문제를 생성한다.

이를 통해 사용자의 이전 학습 결과가 다음 학습 과정에 반영되는 개인화 학습 구조를 구현한다.

### AI 기술과 기능 연결

| AI 기술 | LearnLoop 적용 기능 |
|---|---|
| 생성형 AI | 요약, 질문 답변, 문제 생성, 해설 생성 |
| RAG | PDF 강의자료 검색 및 근거 기반 답변 |
| Long-term Memory | 오답, 정답률, 취약 영역, 학습 기록 저장 |
| 개인화 생성 | 취약 영역을 반영한 복습 문제 생성 |

## 7. 사용 기술 스택

LearnLoop는 개인 개발자가 구현과 배포를 끝까지 진행할 수 있도록 비교적 단순한 구조의 기술 스택을 사용한다.

### Backend

- Python
- FastAPI

FastAPI를 사용하여 PDF 업로드, 질문 답변, 문제 생성, 학습 기록 저장, 취약 영역 분석 등의 API를 구현한다.

### Frontend

- HTML
- CSS
- JavaScript

초기 버전에서는 별도의 React 프레임워크를 사용하지 않고 기본 HTML/CSS/JavaScript로 구현한다.

이를 통해 프론트엔드 학습 부담을 줄이고 AI 기능 구현에 집중한다.

### 생성형 AI

- Gemini API 또는 OpenAI API

주요 활용 기능은 다음과 같다.

- PDF 내용 요약
- 강의자료 기반 질문 답변
- 예상 문제 생성
- 문제 해설 생성
- 취약 영역 기반 복습 문제 생성

초기 개발에서는 하나의 LLM API만 사용하여 시스템 복잡도를 줄인다.

### PDF 처리

- PyMuPDF

업로드된 PDF에서 텍스트를 추출하고 페이지 정보를 함께 저장한다.

페이지 정보를 보존하여 RAG 답변에서 참고 페이지를 표시할 수 있도록 한다.

### Embedding

- 사용 중인 LLM 서비스의 Embedding API 또는 별도의 Embedding 모델

PDF에서 추출한 문서 조각과 사용자 질문을 벡터로 변환하여 의미 기반 검색에 활용한다.

### Vector Database

초기 MVP에서는 다음 중 하나를 사용한다.

- ChromaDB
- FAISS

개인 프로젝트의 초기 버전에서는 ChromaDB를 우선 고려한다.

PDF 문서의 임베딩 데이터를 저장하고, 사용자 질문과 유사한 문서 조각을 검색하는 RAG 기능에 활용한다.

### 일반 Database

- SQLite

초기 MVP에서는 SQLite를 사용하여 다음 데이터를 저장한다.

- 사용자 정보
- 업로드한 학습자료 정보
- 생성된 문제
- 문제 풀이 기록
- 정답 및 오답
- 학습 주제별 성취도
- 취약 영역

서비스 규모가 커질 경우 PostgreSQL 등으로 확장할 수 있다.

### ORM

- SQLAlchemy

FastAPI와 SQLite 사이의 데이터 처리를 관리한다.

### 인증

초기 MVP에서는 복잡한 소셜 로그인 대신 간단한 회원가입 및 로그인 방식을 사용한다.

필요한 경우 다음 단계에서 JWT 기반 인증을 적용한다.

### 버전 관리

- Git
- GitHub

## 8. 시스템 아키텍처 초안

LearnLoop는 하나의 FastAPI 서버를 중심으로 프론트엔드, AI 기능, RAG, 학습 기록 데이터베이스가 연결되는 구조로 구성한다.

### 전체 구조

사용자 브라우저  
→ HTML / CSS / JavaScript  
→ FastAPI Backend  
→ AI / RAG / Database  
→ 결과 반환

### 주요 구성 요소

#### 1. Frontend

사용자가 직접 보는 화면이다.

주요 화면은 다음과 같다.

- 로그인 / 회원가입
- 학습자료 업로드
- 학습자료 목록
- AI 질문
- 핵심 내용 요약
- 예상 문제 풀이
- 학습 기록
- 취약 영역
- 맞춤형 복습

Frontend는 HTML, CSS, JavaScript를 사용하고 FastAPI 서버와 API 방식으로 통신한다.

#### 2. FastAPI Backend

LearnLoop의 중심 서버 역할을 한다.

다음 기능을 담당한다.

- 사용자 요청 처리
- PDF 파일 업로드
- PDF 텍스트 추출 요청
- RAG 검색
- LLM API 호출
- 문제 생성 및 채점
- 학습 기록 저장
- 취약 영역 분석
- 맞춤형 복습 문제 생성
- 데이터베이스 조회 및 저장

#### 3. PDF Processing

사용자가 PDF를 업로드하면 PyMuPDF를 이용하여 다음 정보를 추출한다.

- PDF 텍스트
- 페이지 번호
- 문서 이름

추출한 텍스트는 작은 문서 조각으로 나누어 RAG에 활용한다.

#### 4. RAG System

RAG는 사용자의 학습자료를 기반으로 답변을 생성하기 위한 핵심 기능이다.

처리 과정은 다음과 같다.

PDF 업로드  
→ 텍스트 추출  
→ Chunk 분할  
→ Embedding 생성  
→ Vector DB 저장

사용자가 질문하면:

사용자 질문  
→ 질문 Embedding 생성  
→ Vector DB에서 관련 Chunk 검색  
→ 검색된 내용 + 질문을 LLM에 전달  
→ 강의자료 기반 답변 생성

#### 5. Generative AI

LLM API는 다음 기능에 사용한다.

- 질문 답변
- 핵심 내용 요약
- 예상 문제 생성
- 문제 해설 생성
- 맞춤형 복습 문제 생성

AI가 모든 데이터를 직접 저장하는 것이 아니라 FastAPI가 필요한 데이터만 전달하고 결과를 받아 처리한다.

#### 6. Long-term Memory

사용자의 장기 학습 기록은 일반 데이터베이스에 구조화하여 저장한다.

주요 저장 정보는 다음과 같다.

- 사용자
- 학습자료
- 생성된 문제
- 사용자 답안
- 정답 / 오답
- 학습 주제
- 주제별 정답률
- 취약 영역
- 학습 날짜

FastAPI는 필요한 경우 이 정보를 조회하여 AI 프롬프트에 포함한다.

#### 7. Database

초기 MVP에서는 SQLite를 사용한다.

예상 테이블은 다음과 같다.

- users
- documents
- quizzes
- questions
- attempts
- topic_stats

이후 필요에 따라 데이터 구조를 확장한다.

## 9. MVP 범위

LearnLoop의 MVP는 사용자가 PDF 학습자료를 업로드하고, 해당 자료를 기반으로 학습한 뒤 자신의 취약 영역에 맞춘 복습까지 경험할 수 있는 최소 기능으로 구성한다.

### MVP 필수 기능

#### 1. 사용자 구분
사용자별 학습 기록을 분리하여 저장할 수 있어야 한다.

초기 버전에서는 복잡한 소셜 로그인 대신 간단한 회원가입 및 로그인 기능을 사용한다.

#### 2. PDF 학습자료 업로드
사용자는 PDF 파일을 업로드할 수 있다.

업로드한 PDF에서 텍스트와 페이지 정보를 추출하고 RAG에서 사용할 수 있도록 저장한다.

#### 3. PDF 기반 질문 답변
사용자가 업로드한 자료에 대해 질문하면 관련 내용을 검색한 뒤 AI가 자료를 기반으로 답변한다.

답변에는 가능하면 참고 페이지 정보를 함께 표시한다.

#### 4. 핵심 내용 요약
사용자가 선택한 PDF 학습자료의 주요 내용을 AI가 요약한다.

#### 5. 객관식 문제 생성
AI가 학습자료를 기반으로 객관식 예상 문제를 생성한다.

초기 버전에서는 한 번에 5문제 정도를 생성하도록 제한한다.

#### 6. 문제 풀이 및 자동 채점
사용자는 생성된 객관식 문제를 풀고 제출할 수 있다.

제출 후 정답 여부와 해설을 확인할 수 있다.

#### 7. 학습 기록 저장
다음 학습 정보를 사용자별로 데이터베이스에 저장한다.

- 풀이한 문제
- 선택한 답
- 정답
- 정답 여부
- 관련 학습 주제
- 풀이 날짜

#### 8. 취약 영역 분석
주제별 정답률과 오답 횟수를 기반으로 사용자의 취약 영역을 계산한다.

초기 버전에서는 복잡한 AI 분석 모델보다 단순하고 설명 가능한 기준을 사용한다.

#### 9. 맞춤형 복습 문제 생성
저장된 취약 영역과 기존 오답 기록을 참고하여 AI가 새로운 복습 문제를 생성한다.

이를 통해 Long-term Memory가 실제 개인화 기능에 사용되도록 한다.

## MVP 완료 기준

다음 시나리오가 처음부터 끝까지 정상적으로 동작하면 MVP를 완성한 것으로 판단한다.

1. 사용자가 로그인한다.
2. PDF 강의자료를 업로드한다.
3. AI에게 자료 내용을 질문한다.
4. 핵심 요약을 확인한다.
5. 예상 문제 5개를 생성한다.
6. 사용자가 문제를 푼다.
7. 결과와 오답이 저장된다.
8. 사용자가 자신의 취약 영역을 확인한다.
9. 취약 영역 기반 복습 문제를 새로 생성한다.
10. 다시 로그인해도 이전 학습 기록이 유지된다.

이 전체 흐름을 LearnLoop의 핵심 MVP로 정의한다.

## 10. 추가 기능

LearnLoop의 추가 기능은 MVP 완성 이후 개발 여유가 있을 경우 순차적으로 구현한다.

### 우선순위 높음

#### 1. 서술형 문제 생성
객관식 문제뿐 아니라 단답형 또는 서술형 문제를 생성한다.

초기에는 자동 채점까지 포함하지 않고, 모범답안과 해설을 제공하는 방식으로 구현할 수 있다.

#### 2. 학습 통계 시각화
사용자의 학습 데이터를 그래프로 보여준다.

예시:
- 전체 정답률
- 주제별 정답률
- 최근 학습 횟수
- 오답 비율
- 취약 영역 변화

#### 3. 오답노트
사용자가 틀린 문제만 모아서 다시 확인할 수 있도록 한다.

문제, 선택한 답, 정답, 해설, 관련 주제를 함께 표시한다.

#### 4. 학습자료별 진도 관리
각 PDF별로 문제 풀이 횟수, 정답률, 최근 학습일 등을 보여준다.

---

### 우선순위 중간

#### 5. 난이도 조절
문제 생성 시 사용자가 난이도를 선택할 수 있도록 한다.

예시:
- 쉬움
- 보통
- 어려움

#### 6. 문제 유형 선택
객관식 외에 다양한 문제 유형을 제공한다.

예시:
- OX 문제
- 단답형
- 빈칸 채우기

#### 7. AI 학습 추천
현재 학습 기록을 기반으로 다음에 공부할 내용을 추천한다.

예:
"치과도재학의 금속-도재 결합 영역 정답률이 낮습니다. 이 영역을 먼저 복습하는 것을 추천합니다."

#### 8. 학습 세션 기록
사용자가 한 번 공부할 때의 활동을 하나의 세션으로 저장한다.

예:
- 학습 시간
- 풀어본 문제 수
- 정답률
- 사용한 학습자료

---

### 우선순위 낮음

#### 9. 이미지 기반 학습자료 분석
PDF 안의 이미지, 표, 그림 등을 멀티모달 AI로 분석한다.

#### 10. 음성 질문
사용자가 음성으로 AI에게 질문할 수 있도록 한다.

#### 11. 학습 알림
사용자의 최근 학습 기록을 기반으로 복습 알림을 제공한다.

#### 12. Google 로그인
이메일 기반 로그인 외에 Google 계정 로그인을 지원한다.

#### 13. 학습 계획 자동 생성
시험일과 학습자료를 기준으로 AI가 학습 계획을 생성한다.

#### 14. AI Agent 기반 자동 학습 흐름
사용자의 취약 영역을 분석한 뒤 AI Agent가 자동으로 다음 복습 자료나 문제를 준비하도록 확장할 수 있다.

## 12. 최종 결과물과 과제 요구사항 대응

LearnLoop는 코디세이 Final Project의 요구사항을 충족하도록 다음과 같은 결과물을 완성한다.

### 1. 생성형 AI 또는 AI Agent 핵심 기능

LearnLoop는 생성형 AI를 핵심 기능으로 사용한다.

주요 AI 기능은 다음과 같다.

- 업로드한 학습자료 기반 질문 답변
- 핵심 내용 요약
- 예상 문제 자동 생성
- 문제 해설 생성
- 취약 영역 기반 맞춤형 복습 문제 생성

생성형 AI는 단순한 보조 기능이 아니라 LearnLoop의 학습 흐름 전체에서 핵심 역할을 담당한다.

---

### 2. 필수 기술 요소 최소 2개 이상 사용

LearnLoop는 다음 두 가지 기술을 핵심 기술로 사용한다.

#### RAG

사용자가 업로드한 PDF 학습자료를 Chunk 단위로 분할하고 Embedding을 생성한 뒤 Vector Database에 저장한다.

사용자가 질문하면 관련 내용을 검색하여 해당 학습자료를 근거로 AI가 답변하도록 한다.

적용 기능:

- 학습자료 기반 질문 답변
- 핵심 내용 검색
- 예상 문제 생성 시 관련 자료 활용
- 취약 영역 복습 문제 생성 시 관련 자료 활용

#### Long-term Memory

사용자의 문제 풀이 결과와 학습 기록을 데이터베이스에 지속적으로 저장한다.

저장된 기록을 이후 학습에 활용하여 개인화된 복습을 제공한다.

저장 정보 예시:

- 문제 풀이 기록
- 정답 및 오답
- 주제별 정답률
- 취약 영역
- 최근 학습 기록

적용 기능:

- 학습 기록 유지
- 취약 영역 분석
- 맞춤형 복습 문제 생성
- 이전 학습 결과를 다음 학습에 반영

따라서 LearnLoop는 과제의 필수 AI 기술 요소 중 RAG와 Long-term Memory 두 가지를 충족한다.

---

### 3. 외부 접근 가능한 서비스 배포

완성된 LearnLoop는 외부 사용자가 브라우저에서 접근할 수 있도록 배포한다.

배포 후보:

- Render
- Railway

배포 후 다음 기능이 외부 환경에서도 정상적으로 동작하는지 확인한다.

- 회원가입 및 로그인
- PDF 업로드
- AI 질문
- 요약
- 문제 생성
- 문제 풀이
- 학습 기록 저장
- 취약 영역 확인
- 맞춤형 복습 문제 생성

---

### 4. 실제 사용자 최소 5명 테스트

배포 완료 후 최소 5명의 실제 사용자를 대상으로 서비스 테스트를 진행한다.

사용자에게 다음 학습 흐름을 직접 경험하도록 한다.

PDF 업로드  
→ 핵심 요약 확인  
→ AI 질문  
→ 예상 문제 생성  
→ 문제 풀이  
→ 결과 확인  
→ 취약 영역 확인  
→ 맞춤 복습

테스트 이후 다음 항목을 중심으로 피드백을 수집한다.

- 사용 방법을 이해하기 쉬운가
- PDF 업로드 과정이 편리한가
- AI 답변이 학습자료와 관련성이 높은가
- 요약이 학습에 도움이 되는가
- 생성된 문제가 적절한가
- 문제 풀이 및 결과 확인 과정이 편리한가
- 취약 영역 분석이 이해하기 쉬운가
- 맞춤 복습 기능이 실제 학습에 도움이 되는가
- 개선이 필요한 기능은 무엇인가

수집된 피드백 중 실제 적용 가능한 항목을 선정하여 서비스를 개선하고, 개선 전후 내용을 기록한다.
