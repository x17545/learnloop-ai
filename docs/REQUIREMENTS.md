## 3. 상세 기능 요구사항

### FR-001 회원가입

**설명**  
사용자가 LearnLoop 계정을 생성한다.

**입력**
- 사용자 이름
- 이메일
- 비밀번호

**출력**
- 회원가입 성공 여부
- 생성된 사용자 정보

**정상 동작 조건**
- 필수 입력값이 모두 존재한다.
- 이메일이 중복되지 않는다.
- 비밀번호가 정상적으로 저장된다.

**예외 상황**
- 이미 가입된 이메일
- 빈 입력값
- 잘못된 이메일 형식

**우선순위**
필수

---

### FR-002 로그인

**설명**  
등록된 계정으로 로그인한다.

**입력**
- 이메일
- 비밀번호

**출력**
- 로그인 성공 여부
- 사용자 인증 정보

**정상 동작 조건**
- 등록된 이메일과 비밀번호가 일치한다.

**예외 상황**
- 존재하지 않는 계정
- 잘못된 비밀번호

**우선순위**
필수

---

### FR-003 PDF 업로드

**설명**  
사용자가 학습에 사용할 PDF 파일을 업로드한다.

**입력**
- PDF 파일

**출력**
- 업로드 성공 여부
- 문서 ID
- 문서 이름

**정상 동작 조건**
- PDF 형식의 파일만 업로드할 수 있다.
- 파일이 서버에 정상적으로 저장된다.
- 문서 정보가 데이터베이스에 저장된다.

**예외 상황**
- PDF가 아닌 파일
- 손상된 PDF
- 빈 파일
- 허용 크기를 초과한 파일

**우선순위**
필수

---

### FR-004 학습자료 목록 조회

**설명**  
사용자가 자신이 업로드한 학습자료 목록을 확인한다.

**출력**
- 문서 ID
- 파일명
- 업로드 날짜
- 처리 상태

**정상 동작 조건**
- 현재 로그인한 사용자의 문서만 조회된다.

**예외 상황**
- 업로드한 문서가 없는 경우 빈 목록을 표시한다.

**우선순위**
필수

---

### FR-005 PDF 텍스트 추출

**설명**  
업로드된 PDF에서 학습에 필요한 텍스트와 페이지 정보를 추출한다.

**입력**
- PDF 파일

**출력**
- 추출된 텍스트
- 페이지 번호

**정상 동작 조건**
- PDF의 각 페이지에서 텍스트를 추출할 수 있다.
- 페이지 정보를 유지한다.

**예외 상황**
- 텍스트가 없는 PDF
- 이미지로만 구성된 PDF
- PDF 분석 실패

**우선순위**
필수

---

### FR-006 RAG 데이터 저장

**설명**  
추출된 PDF 내용을 Chunk로 분할하고 Embedding을 생성하여 Vector DB에 저장한다.

**입력**
- 추출된 PDF 텍스트
- 페이지 정보
- 문서 ID

**출력**
- 저장된 Chunk 정보

**정상 동작 조건**
- 문서가 적절한 크기의 Chunk로 분할된다.
- 각 Chunk에 Embedding이 생성된다.
- 문서 ID와 페이지 정보가 함께 저장된다.

**예외 상황**
- Embedding API 오류
- Vector DB 저장 오류

**우선순위**
필수

---

### FR-007 자료 기반 질문 답변

**설명**  
사용자가 학습자료에 대해 질문하면 RAG를 이용하여 관련 내용을 검색하고 답변한다.

**입력**
- 문서 ID
- 사용자 질문

**출력**
- AI 답변
- 참고 페이지 또는 근거 정보

**정상 동작 조건**
- 질문과 관련된 Chunk를 검색한다.
- 검색된 내용을 LLM에 전달한다.
- 학습자료를 근거로 답변한다.

**예외 상황**
- 질문과 관련된 자료를 찾을 수 없음
- LLM API 오류
- 빈 질문

**우선순위**
필수

---

### FR-008 핵심 내용 요약

**설명**  
선택한 학습자료의 핵심 내용을 AI가 요약한다.

**입력**
- 문서 ID

**출력**
- 핵심 요약
- 주요 개념
- 핵심 키워드

**정상 동작 조건**
- 선택한 문서 내용을 기반으로 요약한다.

**예외 상황**
- 처리되지 않은 문서
- 텍스트가 부족한 문서
- LLM API 오류

**우선순위**
필수

---

### FR-009 객관식 문제 생성

**설명**  
학습자료를 기반으로 객관식 예상 문제를 생성한다.

**입력**
- 문서 ID
- 문제 수

**출력**
- 문제
- 선택지
- 정답
- 해설
- 관련 학습 주제

**정상 동작 조건**
- 기본적으로 5개의 객관식 문제를 생성한다.
- 문제 내용이 업로드 자료와 관련되어야 한다.
- AI 응답은 구조화된 형식으로 처리한다.

**예외 상황**
- 문제 생성 실패
- 응답 형식 오류
- 학습자료 부족

**우선순위**
필수

---

### FR-010 문제 풀이 및 채점

**설명**  
사용자가 생성된 문제에 답하고 자동 채점 결과를 확인한다.

**입력**
- 문제 ID
- 사용자가 선택한 답

**출력**
- 정답 여부
- 정답
- 해설

**정상 동작 조건**
- 사용자 답과 정답을 비교한다.
- 결과를 즉시 표시한다.

**예외 상황**
- 답을 선택하지 않은 경우
- 존재하지 않는 문제

**우선순위**
필수

---

### FR-011 학습 기록 저장

**설명**  
사용자의 문제 풀이 결과를 데이터베이스에 저장한다.

**저장 정보**
- 사용자 ID
- 문제 ID
- 사용자 답
- 정답
- 정답 여부
- 관련 주제
- 풀이 시간

**정상 동작 조건**
- 문제 풀이 후 기록이 저장된다.
- 사용자별로 기록이 분리된다.

**우선순위**
필수

---

### FR-012 취약 영역 분석

**설명**  
저장된 학습 기록을 이용하여 사용자의 취약한 학습 주제를 분석한다.

**입력**
- 사용자 학습 기록

**출력**
- 주제별 문제 수
- 주제별 정답률
- 오답 횟수
- 취약 영역

**정상 동작 조건**
- 관련 주제별로 학습 기록을 집계한다.
- 정답률이 낮거나 반복 오답이 발생하는 주제를 취약 영역으로 판단한다.

**우선순위**
필수

---

### FR-013 맞춤형 복습 문제 생성

**설명**  
사용자의 취약 영역과 기존 오답 기록을 기반으로 새로운 복습 문제를 생성한다.

**입력**
- 취약 학습 주제
- 이전 오답 기록
- 관련 PDF 내용

**출력**
- 새로운 객관식 복습 문제
- 정답
- 해설

**정상 동작 조건**
- 이전 문제를 그대로 반복하지 않는다.
- 취약 영역을 중심으로 문제를 생성한다.
- 업로드한 학습자료 내용을 근거로 생성한다.

**예외 상황**
- 학습 기록 부족
- 취약 영역이 아직 존재하지 않음
- AI 문제 생성 실패

**우선순위**
필수

- 정답률

- 취약 영역

**정상 동작 조건**
- 로그인한 사용자 본인의 데이터만 조회한다.

**우선순위**
필수

## 5. MVP 핵심 사용자 시나리오

1. 사용자가 회원가입 및 로그인한다.
2. PDF 학습자료를 업로드한다.
3. 서버가 PDF 내용을 추출하고 RAG 데이터를 생성한다.
4. 사용자가 PDF 내용을 질문한다.
5. AI가 자료를 기반으로 답변한다.
6. 사용자가 핵심 요약을 확인한다.
7. 예상 문제 5개를 생성한다.
8. 사용자가 문제를 풀고 채점 결과를 확인한다.
9. 학습 기록이 데이터베이스에 저장된다.
10. 여러 문제를 풀이한 뒤 취약 영역을 확인한다.
11. 취약 영역 기반 복습 문제를 생성한다.
12. 다시 로그인해도 이전 학습 기록이 유지된다.

## 6. MVP 완료 기준

다음 조건을 모두 만족하면 LearnLoop의 MVP가 완성된 것으로 판단한다.

- PDF 업로드가 정상적으로 동작한다.
- PDF 텍스트를 추출할 수 있다.
- Vector DB에 문서를 저장할 수 있다.
- RAG 기반 질문 답변이 가능하다.
- 자료 요약이 가능하다.
- 객관식 문제를 생성할 수 있다.
- 문제를 풀고 자동 채점할 수 있다.
- 학습 결과를 사용자별로 저장할 수 있다.
- 취약 영역을 분석할 수 있다.
- 취약 영역 기반 맞춤형 복습 문제를 생성할 수 있다.
- 재로그인 후에도 기존 학습 기록을 확인할 수 있다.
